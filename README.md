# 🕐 Digital Clock

A modern and responsive digital clock built using HTML, CSS and JavaScript.

## 🚀 Live Demo

https://PrathamPatil2002.github.io/digital-clock/

## ✨ Features

- Live clock
- 12-hour format
- 24-hour format
- AM / PM indicator
- Live seconds
- Current date
- Responsive design
- Modern dark UI
- Gradient digital time

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
